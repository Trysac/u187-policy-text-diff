# Stack

| Tool | Why |
|---|---|
| Python >= 3.10 | Supports required typing features. |
| uv | Reproducible dependency management. |
| hatchling | Minimal, standards-compliant build backend. |
| ruff | Combined linting and formatting. |
| mypy (strict) | Robust type safety; ships `py.typed`. |
| pytest + pytest-cov | Standardized testing and branch coverage. |
| GitHub Actions | CI automation. |
